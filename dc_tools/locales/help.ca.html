Opcions del component: com funciona

Un component dinàmic mostra als seus usuaris unes quantes opcions: el nombre de prestatges, l'amplada, un tipus de porta… Aquest tauler és on les canvien. En aplicar, el component es redibuixa segons les regles dels components dinàmics: les còpies, les peces amagades, les mides, les posicions, els girs i els materials es tornen a calcular a partir de les opcions i de les fórmules. Les opcions les defineix l'autor del component: un component importat d'un fitxer .skp porta les seves, i un de fet aquí les rep a Atributs del component ▸ Opcions….

Com s'utilitza

  1. Selecciona un component dinàmic al dibuix. El tauler segueix la selecció; el títol mostra el nom del component i quantes opcions té. (Si el títol et demana que en seleccionis un, la selecció no és un component dinàmic.)
  2. Canvia les opcions que vulguis (vegeu més avall).
  3. Prem Aplica (o Retorn en un quadre de text). El component es redibuixa, com a un sol pas de desfer.

El tauler

Quadre de textUna opció que escrius: un nombre (en les unitats pròpies de l'opció, com cm) o un text. Un valor que no és un nombre s'avisa i no s'aplica res.
LlistaUna opció que tries d'una llista desplegable. Una opció pot portar una fórmula, que es calcula en aplicar.
Valor de només lecturaUna opció que l'autor deixa veure però no canviar (un preu o una mida calculats, per exemple). Es mostra com a text.
AplicaRedibuixa el component amb les opcions que has canviat (només s'envien aquestes). Un sol pas de desfer.
ReverteixTorna els valors que té ara el component, descartant el que has escrit.
Línia de missatgesSota els botons. Redibuixat quan ha anat bé. Si alguna fórmula no s'ha pogut avaluar, ho diu: aquests atributs conserven el valor.

Mides. Si una opció és LenX, LenY o LenZ, canviar-la redimensiona el component tal com es redimensiona un component dinàmic: la peça s'estira i el que conté la segueix, i després les fórmules de les seves subpeces fixen el que controlen.

Obre el tauler des d'Extensions ▸ Opcions del component dinàmic…, des de la barra d'eines o des del menú contextual d'un component dinàmic.

Atributs del component: com funciona

Un component dinàmic és un component la mida, la posició, les còpies, la visibilitat o el material del qual es calculen a partir d'atributs i fórmules, igual que els components dinàmics dels fitxers .skp. Aquest tauler és on crees i edites aquests atributs. Les dades es desen a la manera pròpia del format .skp, de manera que un component fet aquí continua funcionant quan s'exporta a .skp (amb l'extensió de fitxers .skp).

En cinc passos

  1. Selecciona un component o un grup al dibuix (el tauler segueix la selecció).
  2. Tria les unitats en què s'escriuen les seves fórmules i prem Fes dinàmic.
  3. A l'arbre, tria la peça (el component o una de les seves subpeces) que vols editar.
  4. Afegeix un atribut: tria'n un de predefinit (X, LenX, Copies…) o Personalitzat… per al teu (primer una lletra, després lletres, dígits o _).
  5. Escriu un valor a la columna Valor o =fórmula, o una fórmula que comenci per =. La columna Resultat mostra què dona ara mateix. El dibuix es redibuixa quan prems Retorn.

Cada canvi és un pas de desfer.

El tauler

TítolEl component que s'està editant.
Fes dinàmic + unitatsDona atributs dinàmics al component o grup seleccionat. Les unitats (centímetres, mil·límetres, metres, polzades, peus) són les que les seves fórmules usen per a les longituds: una fórmula =4 en un component en centímetres són 4 cm.
ArbreEl component i les seves subpeces. Cada peça té els seus propis atributs.
TaulaAtribut: el seu nom (en negreta si els usuaris el veuen a Opcions del component). Valor o =fórmula: un valor fix o una fórmula. Resultat: el valor calculat; ? vol dir que la fórmula té un error, i aleshores l'atribut conserva el valor anterior.
Afegeix un atributAfegeix un atribut predefinit (vegeu més avall) o un de personalitzat.
EliminaTreu de la peça l'atribut seleccionat.
Opcions…Com es mostra l'atribut a les persones que usen el component, a Opcions del component: Etiqueta mostrada (el text que veuen); Accés (no visible, només lectura, un quadre de text o una llista); Mostra en (unitats); i, per a una llista, les seves Opcions de la llista: parells d'etiqueta i valor (el valor pot ser una fórmula, =alguna cosa). Això és el que fa d'un atribut una opció que l'usuari pot canviar.

Atributs predefinits

{PREDEFINED}

Escriure fórmules

Una fórmula comença per =. Sense això, el que escrius és un valor fix.

  • Altres atributs. Un nom sol és un atribut de la mateixa peça: =lenx/2. Nom!atr és l'atribut d'una altra peça: =parent!lenx-3.6, =Shelf!z+2. parent és la peça que conté aquesta; self és aquesta peça. Els altres noms es busquen entre la mateixa peça, els seus avantpassats, els seus germans i els seus fills, i res més enllà.
  • Operadors. + − * / ^ (potència) · & uneix text · comparacions = <> < > <= >= (donen cert o fals) · parèntesis.
  • Valors. Nombres (3.5), text entre cometes ("roure"), TRUE i FALSE.
  • Unitats. Una fórmula veu les longituds en les unitats del seu component, i el resultat es converteix de nou. Els angles són en graus.
  • Cert i fals. Només TRUE o un nombre positiu és cert. IF(0, a, b) i IF(-1, a, b) donen b.
  • Errors. Si una fórmula falla (nom desconegut, divisió per zero, un argument fora de rang…) l'atribut conserva el valor anterior i el Resultat mostra ?.

Exemple: un armari amb N prestatges

A l'armari: atribut n = 3, definit com a opció perquè els usuaris el puguin canviar (Opcions… ▸ Accés: quadre de text). A la peça Shelf: Copies = =parent!n-1, LenX = =parent!lenx-3.6 i Z = =(copy+1)*parent!lenz/parent!n. Canviar n a Opcions del component redibuixa l'armari amb tants prestatges, repartits uniformement.

Funcions

{FUNCTIONS}

Els noms no distingeixen majúscules de minúscules. No s'admeten: OnClick i animacions, ni les funcions que llegeixen la geometria (com l'àrea d'una cara).
